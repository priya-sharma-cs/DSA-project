            🧠 How the Monotonic Stack Algorithm Works
        
        

            

                Problem: Given an array of temperatures, return an array answer such that answer[i] is the number of days you have to wait after the i-th day to get a warmer temperature. If there is no future day with a higher temperature, answer[i] = 0.
            

            

                

                    ❌ Brute Force Approach:
                    
For each day, scan forward linearly until a warmer day is found. Worst-case time complexity: O(n²) when temperatures are decreasing.

                

                

                    ✓ Monotonic Stack Approach:
                    
Iterate from right to left (backwards) maintaining a stack of indices with decreasing temperatures. Each day is pushed and popped at most once. Runtime: O(n).
